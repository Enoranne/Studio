L’application locale relie l’UI au moteur PISTE Studio via FastAPI.

- `project.yaml`, `canon.yaml`, `locks.yaml` ;
- catalogue SQLite et scan de `rushes/`, `audio/`, `graphics/` ;

- diagnostic du CLI Tesseract réel.
