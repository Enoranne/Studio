# Note de séparation — Tesseract / Mirage

PISTE Studio ne contient aucun binaire Tesseract, aucun plugin Mirage et aucun
skill Mirage. Il ne modifie ni ne redistribue Tesseract.

Le bridge PISTE Studio orchestre uniquement un exécutable/CLI Tesseract installé
séparément par l'utilisateur et consomme les commandes, schémas et sorties
exposés par cette installation.

Tesseract reste donc un logiciel externe distinct de PISTE Studio.

En particulier :

- PISTE Studio n'est pas une version modifiée de Tesseract ;
- PISTE Studio n'est pas un fork de Tesseract ;
- PISTE Studio ne constitue pas une distribution de Tesseract ;
- PISTE Studio ne concède aucun droit sur Tesseract ou sur les composants
  Mirage ;
- la licence propriétaire de PISTE Studio ne s'applique pas à Tesseract.

Les conditions d'utilisation, licences, restrictions, obligations et notices
applicables à Tesseract/Mirage doivent être vérifiées et respectées séparément
pour chaque usage concerné.

Cette séparation doit être conservée dans les futurs packages, builds,
installateurs et documents de distribution de PISTE Studio.
