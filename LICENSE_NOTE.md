# Note de séparation — Tesseract

PISTE Studio V0.11 ne contient aucun binaire Tesseract, aucun plugin Mirage et aucun skill Mirage. Il ne modifie ni ne redistribue Tesseract.

Le bridge orchestre uniquement le CLI officiel lorsqu'il est installé séparément par l'utilisateur et utilise les commandes/schémas exposés par cette installation.

PISTE Studio ne doit pas être présenté comme une version modifiée, un fork, une distribution ou un substitut de Tesseract.

Les conditions d'utilisation de Tesseract restent celles de Mirage et doivent être vérifiées séparément pour chaque usage concerné.
