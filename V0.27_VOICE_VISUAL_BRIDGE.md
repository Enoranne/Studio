# PISTE Studio V0.27 — Voice-to-Visual Editorial Bridge

## Problème traité

PISTE 0 utilise fréquemment une voix off séparée des rushes visuels. V0.26
pouvait transcrire cette VO, mais son Proposed Edit principal sélectionnait
surtout des segments à partir de transcripts portés par les médias vidéo.

V0.27 ajoute le pont manquant :

```text
VO séparée
→ transcript
→ phrase / intention
→ fenêtres visuelles candidates
→ comparaison de plans
→ proposition de montage virtuelle
→ validation humaine
→ Storyline
```

## Matching

Pour chaque phrase, PISTE Studio combine des signaux explicables :

- mots de la phrase ou intention saisie ;
- titre, description et tags du rush ;
- rating et statut canonique ;
- plages Favorite / Reject ;
- adéquation de durée ;
- profil Semantic Vision du rush ;
- références ciblées situées dans la fenêtre visuelle ;
- embedding texte CLIP local lorsqu’il est disponible.

Le modèle CLIP n’est jamais téléchargé silencieusement. Sans modèle local, le
matching continue avec les métadonnées et les signaux éditoriaux.

## Fenêtres et comparaison

Editorial Vision produit les fenêtres SOURCE candidates. Une zone rejetée à
50 % ou plus est exclue. Les autres candidates sont classées avec leur score,
leurs composantes et leur raison.

La comparaison ne déclare jamais qu’un plan est artistiquement « meilleur ».
Elle expose des différences afin de laisser la décision au monteur.

## Proposition VO→image

Les longues phrases sont divisées en beats visuels bornés afin qu’une même
phrase puisse accueillir plusieurs plans. Le slot temporel va jusqu’au début de
la phrase suivante : les respirations et silences entre phrases ne sont donc
pas supprimés par défaut.

Si la VO est déjà montée, ses timestamps SOURCE sont projetés dans la timeline.
Sinon la proposition est alignée relativement au début de la Storyline.

L’EDL produite reste virtuelle. La VO audio est conservée. L’application
réutilise ensuite le protocole V0.26 :

- confirmation humaine ;
- hash anti-stale ;
- validation timeline ;
- HARD/SOFT locks ;
- checkpoint Undo ;
- transaction Storyline.

## API

- `POST /api/editorial-agent/voice-visual/candidates`
- `POST /api/editorial-agent/voice-visual/compare`
- `POST /api/editorial-agent/voice-visual/propose`

## UI

Le drawer Editorial Agent accepte désormais une source vidéo ou audio/VO.

Le bloc **VO → IMAGE · V0.27** permet :

1. de choisir une phrase ;
2. d’ajouter une intention facultative ;
3. de comparer les fenêtres visuelles ;
4. de prévisualiser les rushes candidats ;
5. de créer une EDL VO→image ;
6. de valider ou rejeter cette proposition.

## Limites assumées

- le score n’est pas un jugement de mise en scène ;
- une correspondance littérale texte/image n’est pas forcément souhaitable ;
- le raccord spatial et émotionnel doit toujours être vérifié ;
- la première recette réelle PISTE 0 reste indispensable ;
- un futur agent LLM pourra enrichir l’intention narrative sans contourner le
  protocole de proposition et validation humaine.
