# PISTE Studio V0.28 — UX Navigation & Context System

## Objectif

Rendre PISTE Studio plus pratique, lisible et découvrable sans masquer sa
puissance ni changer les règles non destructives du moteur.

V0.28 travaille uniquement sur la couche d’interface :

```text
comprendre où je suis
→ comprendre ce que fait l’action
→ retrouver une fonction
→ trouver de l’aide sans quitter Studio
→ adapter la densité de l’interface
```

## V0.28.1 — Langage visuel contextuel

Six domaines disposent d’un accent discret et cohérent :

- VIDEO ;
- AUDIO ;
- TRANSCRIPT ;
- EDITORIAL / AI ;
- DELIVERY ;
- PROJET.

La couleur reste un signal secondaire. Le domaine actif conserve toujours un
libellé textuel et les actions gardent leur nom/icône.

Les nuances peuvent être neutralisées dans les préférences.

## V0.28.2 — Aide contextuelle

Trois modes :

- **Guidée** : micro-explications et conséquence des actions ;
- **Minimale** : uniquement les conséquences importantes ;
- **Désactivée** : interface sans ces textes d’accompagnement.

Le choix est stocké localement et n’entre pas dans le projet.

Les messages restent courts : par exemple « Storyline inchangée »,
« checkpoint avant Apply » ou « appel externe après consentement ».

## V0.28.3 — Recherche universelle

La palette `Cmd/Ctrl + K` devient un point d’entrée transversal.

Catégories :

- **Actions** : exécuter une commande ;
- **Aller à** : ouvrir directement un menu/panneau ;
- **Aide** : répondre à une question de fonctionnement ;
- **Ressources** : workflow, glossaire, raccourcis et principes de sécurité.

Une barre de recherche visible dans la sous-navigation rend cette fonction
découvrable sans connaître le raccourci.

La recherche tolère les accents et combine libellés, mots-clés, résumés et
contenu d’aide.

## V0.28.4 — Actions contextuelles

L’Inspecteur propose une courte rangée **UTILE ICI** selon le domaine actif.

Exemples :

- VIDEO → Source / Fenêtres / Alternatives ;
- AUDIO → Écouter / Loudness / Master Check ;
- EDITORIAL → Agent / Marqueur / Index ;
- DELIVERY → Readiness / Master Check / Export.

Les outils avancés ne sont pas cachés : cette rangée sert seulement de
raccourci prioritaire.

Elle peut être désactivée.

## V0.28.5 — FAQ & Ressources intégrées

Le bouton `?` permet d’ouvrir directement :

- Aide / FAQ ;
- Ressources.

Les réponses restent dans le panneau de recherche universelle et peuvent
renvoyer vers l’outil associé.

Ressources initiales :

- raccourcis essentiels ;
- workflow PISTE ;
- glossaire ;
- principes de sécurité/non-destruction.

## V0.28.6 — Sémantique de l’action

Le footer distingue visuellement la nature de l’action entreprise :

- ANALYSE ;
- PROPOSITION ;
- APPLICATION ;
- RENDU.

Il s’agit d’un repère de nature d’action, pas d’une promesse de succès.

## V0.28.7 — Préférences UX

Préférences locales :

- densité Confort / Compact ;
- nuances contextuelles activées/désactivées ;
- actions contextuelles activées/désactivées ;
- aide Guidée / Minimale / Désactivée.

Ces préférences ne modifient jamais Canon, Storyline ou fichiers projet.

## Principe de conception

V0.28 ne remplace pas l’interface par une nouvelle UI. Elle ajoute une
grammaire visuelle et une couche de découvrabilité à l’interface existante.

Objectif :

> rendre l’intelligence déjà présente évidente, agréable et facile à retrouver.
